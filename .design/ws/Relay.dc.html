Drop policy, in order
1
Full, and the incoming message is a log → drop the incoming log. Logs yield first, by contract.
2
Full, and it is progress/status/result → evict the oldest queued log to make room.
3
No logs left to evict → a newer progress supersedes an older one; otherwise drop the incoming message and count it.
